# 09 · 2026-11-27 经验汇总（脱敏）

## 1. 找新羊毛前先核实四项
推荐给用户之前，自己用 web_fetch 打开服务商**自己的**条款/定价/FAQ 页确认：
1. 条款有没有**明着禁止**代理/VPN/V2ray/隧道（没明禁就算过，不必写明允许）。
2. 是否真 0 元：没有 0.1 元“防刷”试用、优惠码仍有效、不要求绑卡。
3. 出站流量怎么计费（例：GCP e2-micro 免费档每月只含 1GB 出站，且不含发往中国/澳洲，拿来翻墙会按量扣费）。
4. 领取页现在能不能用（缺货、维护、页面崩溃都算不过）。
论坛帖子清单不经核实直接丢给用户，结果多半一场空。

## 3. 广告代币续期平台的自动化
- 只做签到和正规短链任务（AdFoc.us、Linkvertise），跳过有木马报告的 Cuty。
- 不下载、不运行任何文件，不装扩展，不允许通知，关掉无关新标签。
- Linkvertise 连做几个后会变成“等 60 分钟”，跳过即可。
- 用每日定时任务保持剩余时长 ≥5 天，只在出问题时通知用户。

## 4. 网页终端装哪吒（密钥不过沙箱）
- 问题：面板网页终端要 root 密码，而浏览器的密钥填充填不进隐藏的终端输入框；哪吒安装命令含 agent 密钥，不能经沙箱。
- 做法：沙箱 SSH 设**临时** root 密码 → 浏览器用它登录网页终端，从哪吒后台复制安装命令粘贴执行（注意去掉剪贴板工具加的前缀）→ 沙箱 SSH 改 agent 配置（server 指向本机 cloudflared access tcp 隧道端口、tls false、disable_command_execute true）并重启 → 立刻再轮换 root 密码。
- 先在机器上起 cloudflared access tcp 的 systemd 服务，安装命令默认的直连端口往往不通。

## 5. 沙箱小坑
- 沙箱是 aarch64：本地测节点要下 Xray-linux-arm64-v8a，不是 linux-64。
- 沙箱没有 ssh/ssh-keygen：用 python paramiko 生成 ed25519 密钥和连 SSH。
- `pkill -f <字符串>` 若字符串出现在当前命令行里，会把自己的 shell 杀掉；用 `$!` 记 PID 再 kill。
- 往订阅 Worker 里塞一整行 Clash YAML（如 secret 注入的前置节点）后，务必 `yaml.safe_load` 校验输出；少一个 `}` 客户端就报 `did not find expected ','`。

## 6. 订阅维护约定
- 改 Worker 前备份，文件名带原因；新节点进 PROXY（DIRECT 前）和自动选择组；Clash REALITY 加 `support-x25519mlkem768: true`。
- 用户自己领来的现成节点，即便沙箱测不通，用户要求时也可以加，但在巡检里标注“沙箱测不通不算红灯”，并请用户在手机上实测。
- 前置（edgetunnel 优选 IP）以用户本地实测为准，沙箱在美国，延迟不代表国内。
