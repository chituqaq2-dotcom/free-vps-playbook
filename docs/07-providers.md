# 07 · 免费机平台笔记（截至 2026-11）

| 平台 | 免费档 | 适合 | 注意 |
|---|---|---|---|
| Oracle Cloud | E2.1.Micro ×2（1/8 OCPU、1 GB）；A1 共 2 OCPU/12 GB；200 GB 块存储 | 主力节点 | 东京等热门区 A1 长期没容量，靠 Actions 抢；Ubuntu iptables 默认挡端口；空闲回收 |
| Altare | 每团队 6 GB/150% CPU/10 GB，最多 2 个团队 | 大内存容器 | 条款禁公开代理；节点常 "No capacity"/"Node down"（有的宿主节点会连续宕一两天再自己恢复）；proot 无 systemd；单端口（可占为 REALITY）；**Emergency recovery 需要事先有备份/快照且别的节点有空位**，否则按钮灰着只能等 |
| Cloady | 0.5 vCPU/1 GB，10 GB 流量 + 4 CPU-h/月 | 小备用节点、跳板（有 IPv6） | 没有任意端口入站，只有平台给的 HTTPS 域名（可直接跑 VLESS+WS，不必 CF 隧道）；exec API 约 110 s 超时、需要平台 API token（交接时没带过来就用不了）；重部署会丢 apk 安装 |
| PlutoByte | 0.5 GiB/50% CPU/2 GB，1 槽 | 小 REALITY 节点 | **每 7 天手动续期**（剩 24 h 才出按钮），过期停机不删；Google 登录+手机确认，难自动化；域名可疑 |
| Nodaroo | 2 核/6 GB/50 GB 容器（Pterodactyl），1 槽 | 备用 | 免费只能“自动分配”地点（指定要积分）；部分节点被滥用常崩，可删机重抽；2026-11 因挖矿滥用**全站暂停免费建机**，建机还要先加入其备用 Discord；平台会直接删机 |
| ASCS Cloud | E5-2650v0 1 核、实际 256 MB、16 GB，IPv6-only LXC | CF 隧道节点、cron、bot | **每 30 天点免费层确认**；会自己停机；web 终端无法粘贴；一个号可开 2 台，免费档只有加拿大；补货时开通排队数小时；登录偶尔长时间 “Server is busy”；沙箱无 IPv6 时要有 IPv6 跳板 |
| URnetwork | 免费账号 1 个活跃住宅 socks | 家宽出口（解锁/风控） | 速度一般，节点会掉，靠 Actions 轮换 |
| InstaBox 等 microVM | 4C/8G，空闲暂停，最长运行数小时 | 编译/打包 | 条款禁代理，有封号报告——别做节点 |
| switched.cloud（noprofit.space） | LXC 1C/2G/10G，法国，共享 IPv4 端口转发（SSH + 10 个 TCP/UDP） | REALITY 小节点 | 条款允许个人代理；靠广告任务赚代币续期（1 代币=1 天，最多提前 6 天，停机 3 天删机无备份）；一人一号；账号系统无找回密码 |
| Openworld | IPv6 VPS | 备用 | 条款只禁恶意开放代理；常缺货/维护；密码 ≥15 位 |
| Layero / blitz 类 PaaS | 256–512 MB 容器 | 不适合 | 反代缓冲或条款明禁代理+自动扫描；闲置休眠 |
| 住宅代理赠金（注册送几美元） | 1 个共享 ISP IP 按天扣 | 链式落地 | 要过 KYC 问卷（可能问公司、地址、社交主页），约四分之一被拒；赠金每人一次，多号有连坐风险；**注册前先问用户用什么名字** |
| 论坛公开的静态 IP / SOCKS5 | — | 临时落地 | 多人共用、会被爬；只做链式落地，不用来注册重要账号；到期不续费 |

经验：
- 没有就排队等，不要为了"有"去绑卡。
- 面板 web 终端里浏览器 Agent 往往无法自动填密码；改密码的 JS prompt() 填不了时，命令可能其实生效了，先 SSH 验证。
- 出口 IP 的地理库可能和机房不符（例如美国机房出口被谷歌判成澳洲），可向 Google 提交 IP 位置更正。
- 大厂云的“永久免费”小鸡先看出站计费：有的每月只免 1 GB 出站，且发往中国的流量不在免费额度内，拿来翻墙必扣费。
- 用户手机注册海外账号时，插着国内 SIM 卡会被判成中国区，代理全局也救不回来；改区要走官方的国家/地区关联表单。
